## Concepto General
La web permite a las personas recorrer el espacio virtualmente, descubriendo poco a poco todo lo que ofrece el lugar: naturaleza, atardeceres, fogatas, experiencias especiales, gastronomía, eventos y hospedaje. La página cuenta una historia, guiando al visitante a través de un recorrido real por el lugar.

## Estructura de la Página

1.  **Hero Principal:** Primera impresión con impacto emocional y visual (atardeceres/paisaje).
2.  **Sección de Terrazas:** El corazón de la experiencia: fogatas, convivencia y tranquilidad.
3.  **Food Truck y Experiencias Gastronómicas:** Momentos especiales alrededor de la comida.
4.  **Galería de Eventos:** El lado dinámico del lugar: música, DJs y energía social.
5.  **Salón de Eventos:** Espacio versátil para actividades privadas y celebraciones.
6.  **Hospedaje (Airbnb):** Invitación a extender la experiencia y descansar en la naturaleza.
7.  **Momentos Reales:** Galería de vida para generar confianza y deseo.
8.  **Información Práctica:** Ubicación, horarios y detalles logísticos.
9.  **Asistente Inteligente:** Chatbot para atención personalizada y gestión de reservas sin fricción.

## Enfoque de Experiencia
- **Comunicación natural:** Evita el estilo de catálogo frío.
- **Transmisión de sensaciones:** Enfoque en lo que se vive en cada espacio.
- **Recorrido fluido:** Diseño que invita a seguir explorando paso a paso.

## Tecnologías Utilizadas
- **Core:** HTML, Javascript
- **Styling:** Vanilla CSS / Tailwind (configurado)
- **Framework:** Vite + React (según package.json)
- **Componentes:** Radix UI, Motion (Framer Motion), MUI
- **Iconografía:** Lucide React
